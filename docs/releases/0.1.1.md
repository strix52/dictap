dictap 0.1.1 adds **Copy last transcription** to the tray menu and fixes failures that could lose retained audio or deliver text after dictation was cancelled.

## Added

- **Copy last transcription:** copy the latest nonempty saved transcript when it did not reach your text box. Empty failed entries are skipped; success appears only after the clipboard accepts the text.
- The Start menu shortcut opens History. The per-user installer registers dictap in Windows Installed apps.

## Fixed

- An old capture worker could release a newer recording's microphone reservation.
- Restart recovery could delete audio retained after cancellation when moving the WAV failed. Silence cleanup now records pending deletion for recovery.
- Clipboard fallback now rechecks delivery permission. Paste checks the target window's identity and foreground state before sending keys; partial input releases unfinished key presses.
- Settings and dictionary saves preserve newer edits while a request is pending. Failed key saves retain the entered key and the previous working credential.
- Abnormal Gemini Live closes trigger failure handling. Connection attempts leave time for another address and the handshake.

## Upgrade and validation

Download **dictap.exe** and run it to replace the installed copy. History, settings and your saved API key are preserved; no database schema migration or new runtime dependency is required.

Validated with 180 automated tests, formatting, Clippy, a release build, and microphone, clipboard and synthetic-speech Gemini checks. See the [verification report](https://github.com/strix52/dictap/blob/v0.1.1/docs/release-0.1.1-verification.md) for test limits.

Gemini Live transcripts remain provisional because the API supplies no whole-stream transcription completion proof. dictap keeps their audio for Retry. Raycast's search UI was not verified; the Windows shortcut and app registration were verified.
